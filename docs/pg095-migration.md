# Released PG0.9.5 source migration

The active package pins core0.13.0 at3dd672a and published PG0.9.5 wheelSHA `c1c0de7a635ac1b1634ba158eed050b6f6aed993e01f9b463435430c77d846ae`, source1b8355b. The recursive shared source map is regenerated from the reviewed core wheel; old archive/cohort bytes are untouched.

Default `release-0.9.5/auto` CPU fixture behavior remains bounded. Native continuous responses require `release-0.9.5/continuous` and new protocol `yue2-native-final-ar-hidden-response-v2-pg095`, plus `yue2-bf16-sdpa-math-strict-pg095-v1`. Model geometry, dtype, local asset lock, numerical flags and default rates are unchanged. All GAN math stays upstream.

Historical native PG801/core5d measurements and artifacts keep their original identities; their packets require that old environment. This migration establishes source/CPU software admission only, not a0.9.5 native proof, LR calibration, token-generation or acoustic result. Native qualification must use fresh training.
